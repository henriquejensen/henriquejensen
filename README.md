## What I do

I am a software engineer with 10+ years of experience building web and mobile products. Today, my work focuses on frontend architecture, technical leadership, and developer experience.

- **Frontend architecture:** scalable foundations, application boundaries, shared platforms, and maintainable systems
- **Design systems:** multi-brand components, design tokens, Storybook, and visual testing
- **Accessibility:** focus management, alternative navigation, text-to-speech, and accessible component foundations
- **Technical leadership:** architecture direction, mentoring, documentation, standards, and cross-functional collaboration

> My role goes beyond implementation: I create technical direction, make architectural decisions visible, mentor engineers, and help teams operate with greater autonomy.

## Selected work

### [Local RAG assistant for Moodle](https://github.com/henriquejensen/moodle-rag-assistant)

A privacy-oriented question-answering system that indexes course PDFs and generates contextual answers with cited sources. Built with Next.js, FastAPI, Ollama, and ChromaDB.

### [Leitor de Editais](https://github.com/henriquejensen/leitor-de-editais)

A document assistant that uses Retrieval-Augmented Generation to answer questions about public notices and other PDF documents. Built with Python, LangChain, Streamlit, and FAISS.

### [Personal portfolio](https://github.com/henriquejensen/henriquejensen.github.io)

My professional portfolio and selected architecture case studies, built with React, TypeScript, and Vite.
